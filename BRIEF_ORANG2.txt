BAGIAN 2: PALET WARNA (WAJIB DIPAKAI PERSIS, SAMA DENGAN ORANG 1)
====================================================================

Definisikan warna-warna ini sebagai Tailwind theme extension /
CSS custom properties -- JANGAN hardcode hex berulang di banyak
tempat. CEK LEBIH DULU tailwind.config yang sudah dibuat Orang 1 --
kemungkinan besar warna-warna ini SUDAH terdaftar di sana, kamu
tinggal PAKAI, bukan mendaftar ulang.

--vgs-black-void      : #0A0A0C   (background utama, paling gelap)
--vgs-black-surface   : #14161B   (permukaan card, sedikit lebih
                                   terang dari background supaya
                                   ada depth tanpa perlu shadow)
--vgs-black-elevated  : #1C1F26   (elemen "terangkat": navbar
                                   sticky, modal, dropdown)

--vgs-blue-electric   : #2B6FF6   (aksen utama: tombol CTA utama,
                                   link aktif, harga produk, badge
                                   diskon)
--vgs-blue-deep       : #1740A8   (hover state dari blue-electric)
--vgs-blue-glow       : #4C8CFF  (glow tipis border card saat
                                   hover, TERBATAS, jangan jadi
                                   fill besar)

--vgs-silver-bright   : #E8E9ED   (teks judul besar, logo text)
--vgs-silver-mid      : #A7ABB8   (teks body/paragraf di background
                                   gelap)
--vgs-silver-muted    : #6B6F7B   (teks tersier, placeholder,
                                   caption, metadata)

--vgs-gray-border     : #2A2D35   (garis pembatas antar section,
                                   border card kondisi normal)

Warna fungsional (dipakai SANGAT terbatas, hanya untuk makna
fungsional bukan dekorasi):
--vgs-success         : #3DD68C   (stok tersedia, checkout sukses)
--vgs-warning         : #F5A623   (stok menipis)
--vgs-danger          : #F0473E   (habis stok, hapus item)

ATURAN PEMAKAIAN:
- Rasio dominasi: 60% hitam/gelap, 30% silver/abu-abu untuk teks
  dan elemen netral, 10% biru untuk aksen dan CTA. Biru adalah
  AKSEN, bukan warna dominan.
- Kontras teks WAJIB lolos WCAG AA (rasio 4.5:1 untuk teks body,
  3:1 untuk teks besar/judul) di atas semua warna background gelap.

GALERI GAMBAR (kiri pada desktop, atas pada mobile) -- INI YANG
PALING DITEKANKAN, produk harus punya BEBERAPA gambar, bukan satu:
- Gambar utama besar di atas
- Di bawah gambar utama: strip thumbnail kecil (4-6 thumbnail
  terlihat sekaligus, scrollable horizontal jika lebih banyak)
- Klik/tap thumbnail mengganti gambar utama (tanpa reload halaman,
  pakai React state biasa: useState untuk index gambar aktif)
- Highlight thumbnail aktif dengan border vgs-blue-electric
- Di mobile: galeri jadi carousel swipe dengan dot indicator di
  bawah gambar (bukan strip thumbnail kecil yang susah di-tap
  jari) -- boleh pakai library carousel ringan seperti
  embla-carousel-react atau swiper jika dibutuhkan, pilih salah
  satu dan konsisten
- Sertakan interaksi zoom/pembesaran saat gambar utama di-hover
  (desktop) atau di-tap (mobile) -- opsional tapi sangat disarankan
  untuk pengalaman seperti marketplace

INFO PRODUK (kanan pada desktop, bawah galeri pada mobile):
- Nama produk (heading besar, font display)
- RatingStars + jumlah terjual/ulasan
- Harga besar dan jelas (harga coret jika diskon + badge persentase
  diskon)
- VariantSelector jika produk punya varian (misal warna mouse,
  ukuran mousepad) -- pakai komponen Chip/Swatch dari ui/ buatan
  Orang 1, chip aktif diberi border vgs-blue-electric
- QuantityStepper dari ui/ (tombol -, input angka, +)
- Dua tombol aksi pakai Button dari ui/: "Tambah ke Keranjang"
  (varian secondary/outline) dan "Beli Sekarang" (varian primary,
  lebih menonjol dengan vgs-blue-electric)
- Info tambahan: status stok, estimasi pengiriman (boleh dummy)

TAB/SECTION DI BAWAH:
- Tab atau accordion: "Deskripsi", "Spesifikasi", "Ulasan"
- SpecTable: tabel key-value rapi untuk spesifikasi (misal mouse:
  DPI, jumlah tombol, konektivitas, berat -- ambil dari field
  specifications di data produk)
- RelatedProducts: grid kecil ProductCard dari kategori yang sama
  di paling bawah, pakai fungsi getProductsByCategory()
