BAGIAN 2: PALET WARNA (WAJIB DIPAKAI PERSIS, SAMA DENGAN ORANG 2)
====================================================================

Definisikan warna-warna ini sebagai Tailwind theme extension /
CSS custom properties -- JANGAN hardcode hex berulang di banyak
tempat.

--vgs-black-void      : #0A0A0C   (background utama, paling gelap)
--vgs-black-surface   : #14161B   (permukaan card, sedikit lebih
                                   terang dari background supaya
                                   ada depth tanpa perlu shadow)
--vgs-black-elevated  : #1C1F26   (elemen "terangkat": navbar
                                   sticky, modal, dropdown)

--vgs-blue-electric   : #2B6FF6   (aksen utama: tombol CTA utama,
                                   link aktif, harga produk, badge
                                   diskon)
--vgs-blue-deep       : #1740A8   (hover state dari blue-electric)
--vgs-blue-glow       : #4C8CFF  (glow tipis border card saat
                                   hover, TERBATAS, jangan jadi
                                   fill besar)

--vgs-silver-bright   : #E8E9ED   (teks judul besar, logo text)
--vgs-silver-mid      : #A7ABB8   (teks body/paragraf di background
                                   gelap)
--vgs-silver-muted    : #6B6F7B   (teks tersier, placeholder,
                                   caption, metadata)

--vgs-gray-border     : #2A2D35   (garis pembatas antar section,
                                   border card kondisi normal)

Warna fungsional (dipakai SANGAT terbatas, hanya untuk makna
fungsional bukan dekorasi):
--vgs-success         : #3DD68C   (stok tersedia, checkout sukses)
--vgs-warning         : #F5A623   (stok menipis)
--vgs-danger          : #F0473E   (habis stok, hapus item)

ATURAN PEMAKAIAN:
- Rasio dominasi: 60% hitam/gelap, 30% silver/abu-abu untuk teks
  dan elemen netral, 10% biru untuk aksen dan CTA. Biru adalah
  AKSEN, bukan warna dominan.
- Kontras teks WAJIB lolos WCAG AA (rasio 4.5:1 untuk teks body,
  3:1 untuk teks besar/judul) di atas semua warna background gelap.

BAGIAN 6: TUGAS DETAIL KAMU -- KOMPONEN DASAR (components/ui/)
====================================================================

Buat komponen-komponen berikut, semua styling memakai nama warna
Tailwind dari Bagian 2 (bg-vgs-black-void, text-vgs-silver-bright,
dst), JANGAN hex hardcode:

- Button: minimal 2 varian -- primary (bg vgs-blue-electric, hover
  vgs-blue-deep) dan secondary/outline (border vgs-gray-border,
  hover border vgs-blue-electric). Sediakan state disabled dan
  ukuran default + small.
- Badge: untuk label "Baru", "Diskon", "Stok Terbatas" dengan
  warna fungsional (warning/danger/blue) dari Bagian 2.
- Input: untuk form (Login milik Orang 2, filter harga milik Orang
  2). Background vgs-black-surface, border vgs-gray-border, focus
  ring vgs-blue-electric (WAJIB terlihat jelas, lihat Bagian 8).
- QuantityStepper: tombol minus, input angka tengah, tombol plus.
  Dipakai Orang 2 di detail produk dan cart.
- Chip/Swatch: untuk pilihan varian (misal warna mouse). State
  aktif diberi border vgs-blue-electric. Dipakai Orang 2 di detail
  produk.
- RatingStars: rating bintang dari angka desimal (misal 4.5/5).
  Dipakai di ProductCard (kamu, untuk Home) dan halaman Product
  (Orang 2).
- Modal: komponen modal dasar reusable. Cek dulu di Bagian 9 di
  bawah apakah Login akan pakai modal ini.

PASTIKAN semua komponen ini punya props yang jelas dan cukup
generic supaya bisa dipakai ulang oleh Orang 2 tanpa perlu
dimodifikasi -- kalau Orang 2 butuh varian baru dari komponen yang
sudah kamu buat (misal ukuran Button baru), dia harus bisa
menambah lewat props, bukan menulis komponen Button versi baru.
